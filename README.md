# Word Counter

A tiny command-line tool that counts words in a text file. Built as a practice
project for learning the GitHub pull request workflow.

## Usage

```bash
python word_count.py path/to/file.txt
```

It will print the total number of words and the top 5 most frequent words.
This is useful when you want to quickly recieve a summary of a document
without opening it in a full text editor.

## Running tests

```bash
python -m unittest discover tests
```
